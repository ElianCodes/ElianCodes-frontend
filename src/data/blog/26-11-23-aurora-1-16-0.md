A TV remote has four arrows, an OK button and very little patience for a web app that expects a mouse. Give it a home screen full of horizontal rows and you find out pretty quickly whether you built something for a TV or just something that looks good on one.

[Aurora 1.16.0](https://github.com/Get-Coral/aurora/releases/tag/v1.16.0) is out. Aurora is the open-source media client I build as part of [Coral](https://getcoral.dev/). This release makes it easier to sit down and watch something, whether that means a film from your Jellyfin server or whatever’s on live TV right now.

## Live TV next to your Jellyfin library

Aurora can now use an IPTV provider as a media source. Add an M3U playlist or an Xtream Codes source and its channels, films and series can show up alongside Jellyfin titles on Home and in search. IPTV titles use the same player and can appear in My List and your watch history.

You can also set up Aurora with IPTV alone. You bring the source, and the provider determines what’s available. If it supplies guide data, you can see what’s on without opening another app. Jellyfin’s own tuner and DVR are still handled by the Jellyfin client.

## The sofa is a different input device

On Android TV and Google TV, you can move between controls with the remote. Home rows scroll sideways and remember where you were. That makes a real difference when you open a film to see what it’s about, go back and want to keep browsing from the same spot.

There’s a small player update I’m particularly happy to have in this release. The progress bar shows a preview thumbnail when one is available and shows how much video has buffered. Clicking and dragging to seek also works in Safari. If you’re trying to find the scene you fell asleep in last night, that’s the feature you’ll notice first.

## A desktop window and a cinema on Quest

The desktop project uses Tauri and bundles a local Aurora server for macOS and Windows. The tagged README has build instructions for both.

On Meta Quest, the Aurora Cinema build can run as a regular 2D panel. Choose **Watch in the theater** to open an immersive player with five environments that react to the film. You can browse in a window and then take your seat when you’ve picked something.

The GitHub release covers the code for these builds. For desktop and headset setup, see the [platform instructions in the tagged README](https://github.com/Get-Coral/aurora/tree/v1.16.0#meta-quest-builds).

## Try it

If you already run Aurora with Docker Compose, pull the updated image and recreate the Aurora service.

```sh
docker compose pull aurora
docker compose up -d aurora
```

Starting from scratch? The [Aurora page on Coral](https://getcoral.dev/apps/aurora) has the Docker setup, and the [v1.16.0 README](https://github.com/Get-Coral/aurora/tree/v1.16.0#iptv-sources) covers adding your own IPTV source.

If the remote gets stuck somewhere or a stream behaves differently from what you expect, I’d love a [GitHub issue](https://github.com/Get-Coral/aurora/issues) with the device and steps to reproduce it. Keep any provider credentials or private playlist URLs out of the report.
